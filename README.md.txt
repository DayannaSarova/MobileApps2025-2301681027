# Task Manager Mobile App

Мобилно приложение за управление на задачи, разработено за курсова работа по дисциплината „Мобилни приложения“.

## 1. Идея на проекта

Task Manager е Android приложение, което позволява на потребителя да създава, преглежда, редактира, изтрива и споделя задачи.  
Целта на приложението е да предостави прост и удобен начин за организиране на ежедневни, учебни или работни дейности.

Всяка задача съдържа:

- заглавие;
- описание;
- категория;
- дата на създаване;
- статус дали задачата е изпълнена.

Приложението работи локално и запазва данните в SQLite база данни.

## 2. Основни функционалности

Приложението реализира следните функционалности:

- визуализиране на списък със задачи;
- добавяне на нова задача;
- редактиране на съществуваща задача;
- изтриване на задача;
- запазване на задачите след рестартиране на приложението;
- споделяне на задача чрез Share Intent;
- навигация между основните екрани;
- форма с валидация на празни полета;
- потребителски интерфейс в зелена цветова гама.

## 3. Как работи приложението

При стартиране приложението отваря началния екран със списък със задачи.  
Ако все още няма създадени задачи, се показва empty state съобщение с указание потребителят да натисне бутона `+`.

При натискане на бутона `+` се отваря екран за добавяне на задача.  
Потребителят въвежда заглавие, описание и категория. След натискане на бутона `Save Task` задачата се записва в локалната SQLite база данни и потребителят се връща към началния екран.

Всяка задача се показва като отделна карта в списъка. Картата съдържа информация за задачата и три бутона:

- `Edit` – отваря екрана за редактиране и зарежда данните на избраната задача;
- `Delete` – изтрива задачата от базата данни;
- `Share` – стартира Android Share Intent и позволява задачата да бъде споделена чрез друго приложение.

При редактиране се използва същият екран като при добавяне. Разликата е, че данните на избраната задача се зареждат предварително в полетата, а бутонът се променя на `Update Task`.

Данните се пазят локално чрез SQLite, затова задачите остават налични и след затваряне или рестартиране на приложението.

## 4. Архитектура

Проектът използва архитектура **MVVM + Repository**.

Основните слоеве са:

```text
UI Layer
TaskListFragment, AddTaskFragment, XML layouts

↓
ViewModel Layer
TaskViewModel

↓
Repository Layer
TaskRepository

↓
Data Layer
TaskDatabaseHelper, SQLite

↓
Model
TaskEntity
```

### UI Layer

UI слоят съдържа Fragment-ите и XML layout файловете.  
Той отговаря за визуализиране на информацията и обработване на потребителските действия.

Основни екрани:

- `TaskListFragment` – показва списъка със задачи;
- `AddTaskFragment` – използва се за добавяне и редактиране на задача.

### ViewModel Layer

`TaskViewModel` служи като връзка между потребителския интерфейс и Repository слоя.  
Той управлява списъка със задачи и извиква нужните методи за добавяне, редактиране, изтриване и зареждане на данни.

### Repository Layer

`TaskRepository` отделя логиката за достъп до данните от ViewModel.  
Той използва `TaskDatabaseHelper`, за да работи с SQLite базата данни.

### Data Layer

`TaskDatabaseHelper` наследява `SQLiteOpenHelper` и отговаря за:

- създаване на таблицата със задачи;
- добавяне на нова задача;
- извличане на всички задачи;
- редактиране на задача;
- изтриване на задача;
- намиране на задача по ID.

## 7. Потребителски поток

1. Потребителят стартира приложението.
2. Зарежда се началният екран със списък със задачи.
3. Ако няма задачи, се показва empty state съобщение.
4. Потребителят натиска бутона `+`.
5. Отваря се екран за добавяне на задача.
6. Потребителят въвежда заглавие, описание и категория.
7. След натискане на `Save Task` задачата се записва в SQLite.
8. Потребителят се връща към началния екран.
9. Новата задача се показва в списъка.
10. Потребителят може да избере `Edit`, `Delete` или `Share`.

## 9. Стъпки за стартиране

1. Клонирайте repository-то:

```bash
git clone https://github.com/USERNAME/MobileApps2025-FN.git
```

2. Отворете проекта в Android Studio.

3. Изчакайте Gradle Sync да приключи.

4. Стартирайте Android емулатор или свържете реално Android устройство.

5. Натиснете бутона `Run`.
